# 首次公开前隐私与安全检查

日期：2026-10-23。范围：0.3.2 源码、Android 配置、构建和测试脚本、CI、文档及首次 Git 提交；不替代独立审计或对第三方应用的审计。

## 发布内容

采用 `scripts/release_files.py` 的白名单，而非上传整个工作目录。签名私钥、SDK、缓存、模拟器输出、原始参考图、私人微信截图、本地配置和未审阅文件均不发布。只包含一张空首页和一张使用合成关键词的测试夹具截图。测试夹具明确标注“非微信客户端”，只发布源码，不发布其 APK。

首次提交使用 GitHub 的 noreply 邮箱，避免暴露本机 Git 的私人邮箱。发布前检查暂存区与白名单完全相符，并扫描常见令牌、私钥、个人路径和账号标识。自动扫描有覆盖范围限制，不能证明所有秘密都不存在。

Gradle Wrapper JAR 已核对 Gradle 官方 SHA-256，并为 Gradle 8.9 分发包加入官方校验值。CI 第三方动作固定为官方仓库的完整提交 SHA，权限为 contents: read；每次构建先执行发布和 Android 能力检查。

## 应用检查

- 未发现网络上传代码、广告、统计 SDK 或硬编码凭据。Manifest 没有 INTERNET、联系人、外部存储权限；云备份和设备迁移备份已禁用。
- 搜索词通过固定包名的 Intent 交给目标应用，编码处理特殊字符。分享入口只填词，不自动发起搜索。
- 无障碍服务由系统绑定权限保护，只模拟手势；配置不允许读取控件树，不截图。普通任务和首次校准有超时、切换应用取消和请求编号，防止旧回调继续操作新任务。
- 原开发签名私钥只留在本机。脚本里的 `android` 是本地开发密钥的公开测试口令，不是账户口令；每个克隆首次构建生成自己的密钥。公开预览 APK 的签名与本机原预览一致，正式发布需独立保管发布密钥。

## 需要用户知情的行为与限制

- 默认保存最多 200 条搜索历史，位于应用私有目录，未另作应用层加密；可关闭和清空。不能防御已获得设备 root 或本应用调试能力的人。
- 微信搜索会覆盖系统剪贴板，不读取旧内容，不在结束后清空。系统、输入法及微信可能处理该文字，相关政策不受本项目控制。
- 坐标点击不能验证控件语义。布局变化或微信没有位于预期首页时，可能点击错误位置；不能承诺绝不会误触其他操作。应在当前布局完成校准，使用时保持竖屏，发生异常立即退出或关闭辅助服务。
- 不通过本应用的 INTERNET 权限上传，不代表目标平台不接收查询。搜索成功发出也不代表目标平台已返回结果。

构建与入口测试记录见 [TESTING.md](TESTING.md)，实际数据处理见 [PRIVACY.md](../PRIVACY.md)。发布检查脚本可通过 `python scripts/security-check.py --staged` 重复执行。
