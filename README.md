# 一搜 · 安卓主动搜索（NoFeed Android）

<img src="docs/icon-yisou-0.3.6.png" alt="一搜图标：放大镜中的居中竖线" width="72">

一搜是一款开源的 Android 主动搜索工具。在统一的输入框中输入关键词，选择豆瓣、淘宝、闲鱼、微信、哔哩哔哩、拼多多或小红书，即可发起对应应用内的搜索，减少打开首页后被推荐内容打断的机会。

首页采用简洁的输入框与应用图标，右侧“更多”方便选择平台。支持本地搜索历史、默认应用、桌面小组件，以及从其他应用分享文字后搜索。除微信外的六个平台通过应用搜索入口跳转；微信通过首次校准后保存的坐标辅助点击和粘贴，需要主动开启系统辅助服务。应用无需账号，没有广告、订阅或统计 SDK，搜索历史保存在本机。

灵感来自 [NoFeed](https://apps.apple.com/us/app/nofeed/id6745481301)。本项目是独立编写的 Android 实现，与原作者及各目标平台无隶属关系。首页采用关键词输入框和应用图标，不复制原版素材或付费体系。未核实原版停服状态。

## 安装与使用

当前开发预览版：0.7.0（Android 8.0 / API 26 及以上，通用架构）。公开预览包见 [Releases](https://github.com/oldjie/yisou/releases)；本地直接构建产物为 `dist/yisou-0.7.0.apk`。复制到手机，使用系统文件管理器打开安装。系统可能要求允许该文件管理器安装应用。


## 隐私与安全

应用无联网权限、广告或统计 SDK。默认在应用私有目录保存搜索历史，可关闭、逐条删除或清空。微信搜索会覆盖剪贴板，并按保存位置模拟点击；不会读取旧剪贴板、界面控件树或截图。坐标可能因布局变化而误触，应重新校准，具体行为见[隐私政策](PRIVACY.md)。
